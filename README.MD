# 🐾 PETSHOP

O **PetShop** é um projeto de desenvolvimento web que apresenta uma loja virtual de produtos e serviços para cães e gatos.

O projeto foi desenvolvido com o objetivo de proporcionar uma experiência de navegação simples, intuitiva e agradável, permitindo que os usuários conheçam os produtos, serviços e informações da loja.

## 📌 Sobre o projeto

Este projeto faz parte dos meus estudos na área de Desenvolvimento Web, com foco na construção de interfaces utilizando HTML5 e CSS3.

## 🎯 Objetivos

- Desenvolver uma interface simples, acessível e intuitiva.
- Aplicar conceitos de HTML semântico.
- Trabalhar com estilização utilizando CSS3.
- Praticar conceitos de organização e estruturação de páginas web.

## 🛠️ Tecnologias utilizadas

- **HTML5** — Estruturação semântica do conteúdo.
- **CSS3** — Estilização, animações, layouts e responsividade.

## ✨ Funcionalidades

- Página inicial com apresentação da loja.
- Catálogo de produtos para cães e gatos.
- Seção de serviços oferecidos pelo PetShop.
- Apresentação de informações sobre a loja.

2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` no navegador.
